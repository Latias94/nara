# Presented UI Observation and Operations

**Status:** First ordinary-field and independent-provider slice qualified; remaining R11d work open
**Parent:** [R11d](2026-10-23-foundation-architecture-rebaseline-plan.md#r11d-public-observation-and-visible-ui-operation)
**Owners:** Original semantic panel Host, native image Host and frontend interaction adapters

## Complete consumer

Observe two equal-label controls in distinct document/panel scopes. Focus and edit exactly one
through the visible controller, apply its draft, correlate the original submission and result,
Undo/Redo and Save/Reopen without changing the other source. Retained observations must refuse
after output/geometry, instance or text-focus replacement. Extend the existing complete drawn
Inspector/Shell native trajectory and both independently authored native frontend consumers.
CPU domain-command controls remain a separate comparison, not proof of UI operation.

## Selected contract

The native image Host captures an opaque observation only from its currently accepted image.
It retains the original Host, instance token, output occurrence, immutable provider snapshot,
mapping, clip, native geometry and observed text-focus scope. It creates no widget identity,
journal receipt or new GPU owner. Reusing an unchanged panel while another panel presents is
valid; replacement of the observed output/snapshot/mapping refuses.
The original attachment retains a nominal lifetime only while that exact accepted image remains
continuous. Withdrawal/replacement ends it; restoring an earlier receipt, allocation and mapping
cannot revive an earlier observation.

The semantic Host supplies read-only inspection of an exact live instance without staging or
superseding an action candidate. The original submission exposes its original panel/action IDs;
the same callback still receives each result exactly once. Native observation does not dispatch
source actions or reconstruct local controls.

Observed platform input returns through the original native event router. Admission verifies the
captured endpoint before changing pointer, keyboard, IME or modifier state. Pointer targeting keeps
actual occlusion/capture; text requires the observed keyboard endpoint and same text scope. A
separate explicit observed-operation capability admits provider-defined typed semantic requests
through the original callback and services. The provider uses its original control identity,
behavior mapping and reducer; absent support is explicit. Native accessibility remains distinct.
No universal widget IR, string command registry, second mutation path or transport is introduced.

Nara projects its existing latest `UiSemanticSnapshot` through the accepted image mapping and
dispatches original `FocusTarget`/`SemanticAction` requests. Foreign frontends keep their own
snapshot and control types. Local stale control/draft checks remain authoritative after native
endpoint admission. Dispatch acceptance, original action result, persistence terminal and later
matching presentation remain separate observations. The consumer waits for named results with
timeout/cancellation rather than global idle; an unrelated changing output must not block it.

## Acceptance

- Read-only inspection preserves pending original submissions and refuses foreign/retired tokens.
- Observations come only from accepted output; stale/foreign/pending, hidden round trips, geometry
  changes, device retirement and changed text-focus scopes cannot redirect an operation.
- Both actual native provider consumers use public observation/input ports without private receipt
  issuers. Keep all existing source/history/persistence and physical-retirement assertions.
- The drawn workspace uses the same original Inspector/Shell controllers for observed semantic and
  physical input. Disabled/inert, occluded pointer and modal cases have distinct outcomes.
- Independent domain and visible-control paths agree on exact values, one history entry and saved
  source. Exact original action IDs survive observation and asynchronous completion.
- Run focused serial nextest, affected native qualification, independent consumers, correctness
  Clippy, builds, formatting and document links. Record real results and remaining R11d scope.

Full graph tooling, remote agents, OS IME/accessibility, native platform breadth and measured
performance retain their separate qualifications. The full foundation Goal remains active.
