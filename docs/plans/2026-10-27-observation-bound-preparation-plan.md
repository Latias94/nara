# Observation-Bound Authoring Preparation

## Contract

Replace the Workspace, Project Session and Editor Application prepared-authoring entries that
take separate document/revision arguments with the complete retained `EditorDocumentQueryBasis`.
Patch, stable-property and construction preparation reject the wrong source incarnation,
revision or exact Schema admission before interpreting intent. Retained construction also
checks its original draft basis; a new observation cannot authorize an obsolete draft.
Do not capture a fresh basis when receiving an old tool result.

The Scene/Prefab source owner retains its revision-based draft/candidate APIs. Prepared candidate,
inverse, construction mapping, commit-time admission and history stay in those existing owners.
No new query token, transaction executor, compatibility overload or alias is required. The Panel
facade delegates to the complete Session contract instead of manually duplicating its check.
Session keeps its lifecycle and specialized domain gate; independent Workspace use remains safe.

The [qualification record](../knowledge/engineering/verification/2026-10/2026-10-27T155752Z-complete-observation-bases-at-public-authoring-preparation-ingress-d45451eaca544ad2b50a55a66a0ce496.md)
owns actual public/independent/Editor/native verification, the Reference Game test correction and
remaining foundation obligations.

## Delivery And Verification

The parent owns tooling/Session implementation, root tests, contracts and integration. One worker
owns Editor/Application/Panel and the independent panel-consumer migrations; another owns
window-free module and language fixture migrations. Both have disjoint writes, no builds or
formatting. The parent runs Cargo serially with one build job and the root target, and obtains
independent review before a precise local commit and fast-forward merge. Preserve `vendor/`
and unrelated changes. No remote publication.

Use real public regressions for matching revision with a different admitted Schema, missing
Schema, stale revision/incarnation and retained construction. Preserve existing late-operation
atomicity, unknown-record retention, history refusal and non-active-document behavior. Run focused
tooling/Session tests, affected Editor and independent consumers, the actual C#/Lua runner,
no-default coverage and appropriate native Editor qualification. Record exact changed behavior
and verification limits; this does not complete R1/R2/R3 or the full foundation Goal.
