## Verified Source Tokens And Complete Guard

Only the verified corpus can prepare `PreparedSceneExtractionSource` and its nominal Prefab
counterpart. They accept no caller-supplied output. Original capture/Work identity, source kind
and actual changed output are required before ordinary publication-shape and complete source
classification under the same nominal basis and original file policy. The Prefab classifier
borrows real placements/entities/inputs without instantiating a Scene. Future source/history/key
and classification allocations are admitted first. A narrow resolver accessor shares the actual
unpublished Prefab allocation without exposing its private representation enum.

Each token retains exact original document/classification, revision/content/history observations
and an already allocated future checkpoint. Session validation/binding rechecks those facts;
guard drop and `into_prepared` install nothing, while commit performs prepared swaps only.
The corpus additionally pairs each token with its exact output Arc, key, Work and change fact.
Valid tokens from another corpus cannot enter a complete-set installation.

Tooling prepares one fixed optional-token slot per captured member: actual changed sources get
nominal tokens; unchanged guards get none. `EditorPersistenceAuthority` binds the original
Workspace, complete membership and all tokens before taking its first installation step.
Changed Sessions have exclusive owner guards; unchanged Sessions have immutable guard references.
Every container is admitted before allocation/exclusive binding. Failed binding or explicit
release restores the same tokens to fixed positions without allocation, reclassification,
new source identities or budget reset. Final source-only commit changes only actual replacements.
Saved state, external-reload state, navigation and guard histories remain untouched; Q stays closed.

ADR0047 and the CP2 plan now record selective replacement, SaveCurrent and Guard responsibilities.
The latter two publication roles are not implemented by this source guard. Ordinary history
source replay may expose an older composition conflict; guard capture does not authorize clearing
