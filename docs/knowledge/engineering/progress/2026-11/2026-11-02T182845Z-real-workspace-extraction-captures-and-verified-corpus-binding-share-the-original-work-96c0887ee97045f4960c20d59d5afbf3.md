# Details

## Neutral Source Mechanism, Separate Nominal Operations

`authoring/source_checkpoint.rs` now owns private `SourceSnapshot`, `BorrowedSource`,
`FrozenSource` and `PreparedSourceCheckpoint`. CP1 uses those internals while retaining its own
public hidden input/prepared/commit types, retained tokens, field-upgrade proof, lineage and
diagnostic mapping. Frozen capture shares the actual document/classification only after
admission; original Sessions continue owning both history branches. No replacement Session or
history is constructed during capture.

Shared incumbent accounting retains actual raw source/classification and both existing history
branches. It now includes the actual open Prefab `inputs`, which CP1's previous placements/entities
signature omitted. Lorentz's review found that summing inputs still preceded approval of traversal.
The shared callback now carries nodes as well as bytes: O(1) cardinality admits input-scan work
before iteration. CP1 pays its original byte allowance with a specific input-scan stage; extraction
pays the same Kernel nodes/bytes. A real256-input control with ample bytes but16 work nodes refuses,
with empty and sufficiently funded controls. Existing bounded raw-cost/classification walkers
retain their distinct FileLimits and scratch roles; no universal per-instruction budget was added.

`PrefabExtractionWork` retains one nominal operation identity and the original extraction Kernel.
Actual source input APIs retain current revision/content/history limits, original document/state
allocations, nominal basis and published source kind. Capture and validation reject Native Sessions,
live Scene instances, foreign Work and history/source drift. Failed work is never refunded.

## Actual Corpus And Workspace Binding

The hidden concrete `PrefabExtractionRequest` consumes actual captured source allocations,
associations, selected source/root and fixed Q metadata. It calls the existing complete extraction
owner without recapture or a CP1 Schema successor. Refusal returns the same original request
allocations and spent Work, retaining compiler diagnostics/failure observations. Successful review
exposes actual readonly originals/P/Q and verified correspondence through nominal preparation.

`PreparedExtractionCorpus` now separates immutable `VerifiedExtractionCorpus` data from Kernel
work. Its outer `PreparedPrefabExtraction` keeps that exact Work through later validation. No
replaceable mutable Work is exposed; finite methods debit storage, match actual captured members
and validate live Sessions. This avoids resetting a budget after a successful constructor.

Tooling captures the complete ordered open set, source bindings, exact nominal Scene/Prefab inputs
and selected source-owned root. It rejects extension/unbound sources and projection-only roots.
`bind_corpus` checks a complete ordered one-to-one mapping to actual original corpus members,
original allocation/basis/Work identities and the selected canonical source/root. Input, prepared
corpus and mappings return on refusal with spent work retained; corrected retries use the same
candidate. The prepared Workspace wrapper rechecks actual membership, bindings, kind and source
observations through original owners, while allowing navigation changes. It grants no live
replacement, saved checkpoint or publication authority.

Real tests use multiple dirty/inactive sources, both history branches, thread transfer, repeated
instances and actual before/after compilation. They check reference targets rather than only
constructor success, foreign Work despite equal Arcs, Undo/Redo identity drift, Reopen/rebinding,
late membership changes, returned original allocations and exact/one-short total allowances.

checkpoint; Guard writes nothing. Ordinary persistence checkpoint/output association and leaf
