# Scope

Evaluate plugin freedom, replaceable physics, external UI/toolkit integration, custom game UI, package UX, and asset-store readiness without changing architecture authority.

# Current Claim

Nara preserves most ordinary Bevy-like ECS plugin freedom, but cross-plugin role replacement, rich platform input, public render contribution or interop, and clean-room package lifecycle UX remain unproven. Existing render-specific exact-version interop is a candidate, not an accepted public contract.
