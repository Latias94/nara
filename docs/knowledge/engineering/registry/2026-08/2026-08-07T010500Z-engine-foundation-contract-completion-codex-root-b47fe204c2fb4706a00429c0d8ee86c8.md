# Scope

NUI-U15A proves and freezes the shared UI interfaces before product-specific integration. It owns
three neutral thin consumers: the `nara_ui_kernel` layout/frame gallery, the `nara_ui` ECS/Scene
interaction lab including the platform-neutral semantic/accessibility-action boundary, and the
root-facade presentation gallery including one neutral candidate-to-packet-to-matching-receipt-to-
activation round trip. AccessKit remains outside this conformance unit.

# Current Claim

NUI-U17 is complete. NUI-U15A is the only active implementation unit. It may fearlessly refactor an
owning module or public seam when a neutral example exposes a shared invariant, dependency-direction,
or lifecycle defect. It may not derive a framework, registry, component catalogue, adaptive-layout
policy, private integration hook, or product-specific vocabulary from the examples. NUI-U15B remains
blocked until the three public-interface consumers pass and one baseline records the public inventory,
named shared semantic invariants, exact assertions, and proving commit.
If U15A changes a shared public UI API or feature surface, it mechanically migrates only the affected
Reference Game imports/adapters and leaves complete product acceptance to U15B.

# Handoff

Implement the examples in dependency order: kernel layout/frame, runtime authoring/interaction, then
root presentation composition. Keep scenario construction local to each example and reusable behavior
inside its owning deep module. Run only the focused conformance and affected module gates. At U15A
closure, audit public imports and dependencies, record the exact freeze commit and admitted surface,
record the named shared invariants and assertions, and activate U15B without allowing Reference Game
state, layout, copy, package, smoke, digest, or pixel concerns to reshape the shared APIs. Keep the
existing first-party Reference Game compiling after a shared public-interface change, but do not count
that mechanical migration as product evidence. Any later shared behavior or conformance-assertion
change reopens U15A even when public signatures do not change.
