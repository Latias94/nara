# Result

RPR-U3 is complete at `676d030518168127335a7d426f34b1b2ae0078d0`.

`ProductRecipe` now owns replayable runtime-only plugin entries and typed canonical configuration.
`SchemaContribution` binds a schema-owning plugin to its provider definitions once. Direct `App`
composition installs that contribution's provider authority before the plugin builds; file-backed
Hosts preload and freeze the same definitions. Divergent executable receipts reject before App or
runtime publication, and direct/file-backed schema composition fingerprints agree.

`HeadlessRun::from_recipe`, `DesktopRun::from_recipe`, and
`EditorProjectIntent::with_recipe` hide project admission, candidate publication, and bounded close
plumbing from ordinary authors. Raw one-shot plugins remain available to direct `App` composition,
while definitions, slot edits, provider lists, and retirement control remain advanced embedding
surfaces during the RPR-U4 migration.

The unit added no Python tool, workflow, benchmark protocol, approval model, or evidence schema. It
reused existing Rust integration tests and public-prelude fixtures. Independent review found one P1
before commit: direct `App` composition originally ignored contribution provider definitions. The
shared schema-authority installation and direct/file-backed divergence regression fixed that gap;
no unresolved P0/P1 remains in the reviewed U3 scope.
