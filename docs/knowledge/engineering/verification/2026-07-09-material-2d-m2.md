# Material and 2D Migration M2 Verification

## Scope

- Added `nara_material` as the backend-neutral material/sampler domain.
- Removed image-owned sampler policy from `ImageAsset`, `ImageImporter`, `PreparedImageResource`, and image descriptor hashes.
- Migrated sprite and tilemap authoring to material-first wrappers.
- Migrated `nara_sprite_render` extraction, queueing, sorting, and batching to `SpriteMaterialKey`.
- Split `nara_render_wgpu` image texture upload cache from material/sampler bind-group cache.

## Notes

- Sampler changes now affect material keys and wgpu bind-group selection, not image import or prepared image resource identity.
- Sprite/tilemap batching groups by material key. For same layer/sort key, material key sorts before source order so equal materials can merge; users should express strict draw ordering with layer/sort key.
- Runtime UI should reuse `nara_material`, prepared image resources, and material-keyed queueing rather than creating a separate image/sampler path.
