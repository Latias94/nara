# Result

## Typed code-free transport and concrete cancellation

The shared [recovery transport](../../../../../src/project_host/authoring/recovery_storage.rs)
retains each concrete immutable `Arc<P>` through prepared package, stored package, bound Pending
and confirmed Pending stages. `RecoveryPackageData` projects fixed bytes/digest, source universe,
old/final Ready definitions and protected paths only. It has no payload decoder callback,
Schema-successor policy or semantic execution hook. CP1 keeps its concrete payload admission in
[source_upgrade_storage.rs](../../../../../src/project_host/authoring/source_upgrade_storage.rs);
extraction has its own [concrete loader](../../../../../src/project_host/authoring/project/prefab_extraction/recovery_data/storage.rs).

Fresh loading first observes the actual Pending manifest and package, enforcing the encoded-byte
ceiling and length/digest commitment before concrete decoding. The concrete operation then binds
its admitted immutable allocation to those same observations and revalidates the current names,
configuration and protected location. A read issues no historical replacement receipt. Package
publication precedes Pending publication; the final Ready definition is retained data, with no
Ready admission or source-publication authority granted by this transport.

The actual [ProjectPrefabExtractionStorage](../../../../../src/project_host/authoring/project/prefab_extraction/outputs/storage.rs)
consumes the complete fixed-output/recovery owner. Original Review, nominal checkpoints, output
allocations, source Work and Host budget move together through each physical phase. Refusal,
failure, uncertainty and cleanup retain their actual stage and incumbent owners for retry.
Confirmed Pending is the terminal stage of this slice; it publishes no Q, sidecar or dependant
source.

Ready cancellation settles native cleanup and uncertain outcomes, drops native publishers and
observations, and restores exclusive package ownership before refunding only released live
storage/handles. An escaped shared Arc keeps cancellation refused. A confirmed package may remain
as an orphan while Ready is unchanged; its actual publication receipt remains owned and charged
by the cancellation record until that record ends. A possible Pending replacement fences this
cancellation path. A refusal before entering its file publisher creates no new fence, and a later
pre-publisher refusal cannot clear a fence from an earlier actual attempt. Source Work is never
refunded, and fixed outputs/checkpoints retain their original cancellation owner.
