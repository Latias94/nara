# Verification

Commit `aed0729` removes the ambiguous WGPU frame counter from product evidence. The backend now
retains the App frame captured with the product world and the Render transaction identity owned by
the exact `RenderFramePacket` as separate facts through queue submission and GPU completion.

# Result

- `WgpuFrameTransactionStats` exposes explicitly named App-frame and Render-transaction identities.
- `WgpuFrameCompletionSample` carries both identities and no longer offers an ambiguous
  `frame_index` accessor.
- The completion token records both identities at the queue-submission boundary.
- Existing root examples and the Reference Game candidate compile against the explicit Render
  transaction accessor.
- A regression with App frames `10` and `11` paired with Render transactions `9` and `10` proves
  exact correlation without offset arithmetic.
