# Qualified Scope

The working tree based on `6ef3cb0` qualifies immutable Input definitions and the global source
action-map workflow. This evidence accompanies the source implementation commit; it does not
qualify processed startup Input, all physical endpoint growth, a visual action editor, render
graph implementation or the complete foundation Goal.

`ActionMapDefinition` replaces live mutable binding authoring and serde. Code and strict canonical
`action_map` JSON use one bounded compiler. Actual owner-backed bindings capture the private
compiled allocation once; changing an owner's later projection cannot change installed data.
World-local `ActionMap`, `ButtonInput` and `SemanticActions` are move-only. Context slots and
non-reverting staging preserve paused input, held cancellation, aggregation and fresh presses.
State reservations follow queued and held lifetime identities; source reservations follow the
actual definition owner. Compiled replacement is infallible within the fixed state allowance;
candidate compilation and source/receiving admission remain fallible.

Source projection preserves the selected path as an explicit obligation, while source-independent
projection continues refusing it. The real loader reads exact project-relative bytes, admits
intrinsic primary Product identity and optional sidecar agreement, joins existing canonical
identities and records the Input member/digest. Installation occurs once in candidate admission
before Scene materialization and Startup, rejecting explicit code maps, including empty ones.
Travel verifies and reuses the original owner without resetting World state; Ready commits use
captured facts. Check and source Export retain and relocate exact Input bytes. Authoring startup
capture and supervised source receipts use the same actual source facts and content digest.

# Independent Review And Corrections

Bounded independent review challenged actual definition custody, state refunds after queued
observations, private installation authority, canonical identity, travel and Authoring facts.
The final captured-data review also covers safe owners with dynamic `AsRef` projection. No
confirmed remaining P1/P2 remains in these reviewed scopes. Review is separate from execution.

Authoring read-memory review exposed admission after buffer allocation. The repair reserves the
buffer/decoder and source fact before copying/opening/reading, retains only actual facts after
temporary compilation, and preserves original single-file ceilings for aggregate-budget
diagnostics. New tests prove no file/encoded progress on insufficient memory and correct
one-short Input/sidecar aggregate refusal. Later review closed both findings.

# Remaining Foundation Work

Processed Input still needs complete Runtime Product configuration, selected codec/acquisition,
global retention and a prebuilt source-free physical process proof. The concrete R10 endpoint
admission correction remains open: unique physical endpoints and semantic contributions must have
finite mutation-boundary admission across drained frames. The fixed context/revision allowance
does not imply that complete Input bound. Seat/gamepad/axis, replay vocabulary and a visual
action-map editor retain their separate consumer requirements. Target build selection, rendering
and the custom-drawn Editor continue under the full foundation plan.
