share that member. Portable paths reject case/ancestor aliases, device names, traversal and
filesystem component-limit mismatch. Required graph edges close; soft references remain inert;
startup/later Scenes and explicit addressable roots are declared. Base capture returns no file
capability. Existing base acquisitions use the original captured bytes and exact plan after all
catalog/startup/bundle files are removed and the later member is corrupted.

and Required declarations. A claimed dependency table alone is insufficient. Concrete resource
decode checks format/version, the family membership query and the codec's new complete enclosing
source/product query for every mapping. A valid payload for a foreign source or with an absent
auxiliary product refuses. Panic/refusal publishes no decoded output or World mutation.

The retained current-Scene owner accepts real Expanded/Runtime candidates through one private
closed input selection. Startup, Restart, replacement, native claims, commit/discard and weak
views keep the same owner. Runtime candidates carry actual definitions; no source expansion,
ProjectManifest, source receipt or asset metadata is manufactured. A base Scene retains its exact
decoded reservation and base through current-Scene retirement. Independent tests execute actual
managed native Caption components and the concrete CPU bundle; they do not claim automatic native
asset residency or a generic packaged Project Host.

Catalog and base budgets are separate logical ledgers. Root caps constrain raw input and actual
catalog owner residual before I/O/decode, then member capture and concurrent decode promises.
Shared output clones retain one reservation. Held overlapping decoders reject excess admission;
Scene budget remains occupied while the current Runtime owns it and returns after physical
Runtime retirement. Compiled plugin/Schema construction, syntax scratch and trusted codec
allocations retain their stated owner contracts. These guarantees do not measure allocator/RSS.
