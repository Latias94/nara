and complete current/predecessor catalogs. Raw and snapshot constructors share composition and
fingerprint validation, including predecessor/tombstone claims. Snapshot input checks owner count
and aggregate catalog allowance before each push; it neither deep-clones nor readmits catalogs.

Scene lends nominal prepared-source views only after the same original revision/previous-basis
check as commit bind. The views borrow both session and candidate, share the original source Arc
and expose its successor classification. They cannot replace the live source or commit while
borrowed. Same-content independently admitted metadata remains nominally distinct.

The root Authoring owner composes one missing generation-one owner and engine-owned Adapters,
admits one basis, prepares bytes/settings/path/digest and binds the publisher while the incumbent
leaf remains alive. Equal existing complete lineage is AlreadyAdmitted only after original
manifest/bundle observations agree; existing-owner differences reject. This no-op also covers
already evolved owners; the generation-one restriction applies to a newly added owner.

Accepted publication retains actual target leaf name as well as candidate capability/evidence.
Attachment checks original previous identity, actual target name and parent, verified bytes and
candidate identity, then moves that accepted capability into the new metadata receipt. It does
not reacquire by cached identity/digest, readmit Schema or grant execution. Rejection retains the
exact prepared metadata and accepted leaf/evidence for reconciliation. The admitted manifest leaf
is Arc-shared across predecessor/successor rather than closed and reacquired.

Current Scene capture uses the existing selected compiler/acquisition against validated successor
source views and open dirty Prefab snapshots. A demanded dirty Prefab retains its actual original
Arc, file observation and revision. Before bundle publication, capture review exposes only
readiness/diagnostics/failure observations. Full capture attachment requires the same nominal
basis and an actual accepted successor receipt. Normal validation then uses that successor's
manifest/bundle observations, not a mislabeled incumbent receipt.

One operation budget accumulates all successful/failed current captures. Validation/attachment
reject an exhausted budget, even if an earlier capture succeeded. Metadata receipt baseline and
the operation's final usage are separate; future independent captures do not inherit the prior
operation's complete cost. Data ownership uses the existing logical model, not allocator/RSS
isolation. No new generic Schema executor, file publisher or source interpreter is introduced.
