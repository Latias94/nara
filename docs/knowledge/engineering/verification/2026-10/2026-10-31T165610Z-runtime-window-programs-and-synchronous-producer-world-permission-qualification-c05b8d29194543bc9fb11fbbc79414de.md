# Result

Ordinary Runtime windows now execute through the same Host-local typed-program transaction as
Scene, Canvas, embedded Game and independent image consumers. Root owns the Host and lazy producer
with its original capture/result, UI/Input, READY, observation, telemetry-seal and native-close
responsibilities. The physical-resolution final surface consumer joins the original encoder,
reservation and queue submission. Output admission, present, UI settlement and physical completion
remain distinct.

Independent review drove concrete corrections:

- Missing first window targets do not pin a foreign registry. Actual surface admission fixes the
  original authority, including partial native construction that must retain its original owner.
- Capture identity comes from RuntimeInstance; its associated input has private construction.
  Replacing the World generation faults/refuses before an incorrect capture can be issued.
- Native preparation freezes actual cache-plus-graph resource bytes once for telemetry and
  preallocated UI result facts. Original completion identity and logical routing are preserved.
- Known final-consumer metadata/retention joins preflight before allocations. Its prepared native
  draw follows the same failure/panic/upload prefix as the program.
- World-presentation guards belong to each producer and the keyed device-loss registry. Producer
  and Host share one private revoker slot: Drop revokes before returning without maintenance.
  Old snapshots and delayed result return cannot restore permission; Editor Game uses the same slot.
- A foreign Runtime's geometry cannot revoke the original producer before stale-source refusal.
- Successful presentation to an occupied physical window revokes displaced world permissions,
  while another window remains valid. Revocation precedes optional new picking-map construction:
  an admitted physical packet with zero logical scale can replace pixels without issuing picking
  permission. Both same-producer and different-producer replacements are covered.
- Packet admission and actual native submission counters remain separate. Valid packets with no
  available surface report admission and zero native submits.

Concrete Backend storage is now internal. Its public/prelude export and old Runtime executor are
removed without aliases. CPU Runtime tests use the production Host. Remaining quad/window/Canvas
numerical comparison helpers compile only for tests; the mutable WorldCanvas cache is absent from
production. The stock central capture payload remains until typed policy capture consumers migrate.
