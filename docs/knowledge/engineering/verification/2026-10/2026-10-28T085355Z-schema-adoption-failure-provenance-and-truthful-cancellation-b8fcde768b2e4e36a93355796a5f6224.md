# Follow-up

Keep the complete foundation Goal active. Existing-owner Schema evolution, actual executable
gameplay ownership, source-free delivery, rendering/time and Nara-owned UI remain independent
work. No native rendering, .NET prerequisite workflow or whole-workspace suite is requalified
merely by these diagnostic changes; predecessor evidence retains its exact source and scope.

Parallel read-only investigations identified the next local lifecycle boundaries:

- The persistent single execution slot cannot represent all installed members, disabled
  required dependents or exact installation bindings. Evolve its one selection-file authority
  into a bounded installed set with an independent desired slot and explicit requirement
  bindings. Compare this against a separate installed ledger before reconciling ADRs 0020,
  0035 and 0118. Do not turn already selected local relationships into a Cargo/NuGet resolver,
  automatically execute dependencies or imply shared assembly resolution.
- Graph withdrawal must cover disabled reverse dependents and an exact stale-sensitive cascade
  review. File reclamation remains a separate owner obligation after route withdrawal and
  actual child/IO/publication return; stopping a route alone does not authorize deletion.
- Installation receipts and equal bytes do not grant file deletion rights. Preserve continuous
  created custody when available; across Close/Open use bounded management/protection facts
  plus a fresh explicit removal review of current objects. Modified/adopted samples, unknown
  files and dirty document-owned sources must survive. Durable records cannot recreate old
  native handle authority or authorize automatic deletion after fresh Open.
- Trace a narrow filesystem operation that validates bounded contents under stable custody
  and removes that same object. Qualify the actual platform guarantee before enabling it;
  no name-based deletion fallback or recursive cleanup follows from an inspection. Partial
  removal, cancellation and uncertain persistence need truthful retained facts, not rollback.
