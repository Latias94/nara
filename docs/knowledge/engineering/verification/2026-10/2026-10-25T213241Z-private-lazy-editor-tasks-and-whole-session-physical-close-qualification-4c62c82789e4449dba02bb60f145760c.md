# Verification

This is the bounded private-lazy Editor deployment and whole-Session physical-close successor
under R4b, based on `f69ac8785947cd693a25e14e8601f09932ee88f7`. Its final containing commit binds
the qualified source and evidence; the metadata commit above identifies the starting revision,
not a claim that the base already implements this unit. All Cargo runs use Rust 1.95.0, jobs1,
serial commands and the existing checkout `target` on F:. No push, PR or new C:/D: build directory.
Previously identified C: PDBs were already removed; unrelated D: project artifacts remain intact.

The selected physical isolation policy follows the matched lazy/shared Image comparison, not
worker-count folklore. `TaskPlugin::lazy` owns its ordinary close participant before exposing its
facade, rejects a preoccupied facade and has distinct canonical configuration. Only Editor
authoring and trusted in-process Play select it; default Tasks and shipping remain eager.

Irreversible Session close reuses the existing Runtime owners and retirement driver. It neither
drives gameplay nor fulfills Restart. Prepared, failed, active and caller-held native activation
owners remain accountable; live in-flight Game completion stays exact. A physically Stopped lower
Runtime ends its existing epoch without invoking unavailable frame ports or fabricating an ack.
Completed reports aggregate disjoint owners once. Actual Tasks acquisition before construction
retirement determines its report requirement, not the name of the outer error variant. Application
and native final results retain completed cleanup failures independently of physical completion.
