# Result

The generic render frame now carries the original selected typed policy capture through ordinary
Runtime windows, Scene, authoring Canvas, embedded Game and independent image consumers. A policy
definition freezes implementation and device requirements; installation owns new capture admission;
accepted input retains its original execution lease; CPU Feature instances belong to a producer;
native state belongs to an instance and device epoch. Closing an installation refuses new capture
without reinterpreting or revoking already accepted input. Producer close remains irreversible.

`WgpuCapturePlugin`, `WgpuWindowPresentationPlugin`, `WgpuStockPolicyPlugin`,
`WgpuStockSpritePlugin` and `WgpuStockUiPlugin` compose explicitly. Embedded Editor Play uses the
same capture/policy/contributors with embedded presentation. `stock-sprite` and `stock-ui` replace
the old submitter feature names without aliases. Production central package payloads, domain
collection matches and combined image facades are deleted. Numerical comparison helpers retaining
the old drawing representation compile only under tests; they provide scoped independent oracles.

The standalone scalar-field policy consumer uses ordinary ECS capture, its own shader/uniform/native
Feature, actual Runtime window presentation and the same production Host. After original Runtime
retirement, a sibling input with the same installation and Capture Arc reconstructs on a new image
Host. Every pixel matches the independent CPU oracle. It contains no stock drawing or private
executor, and does not claim temporal effects or source/processed UI support.

Independent review drove the following owner corrections:

- Bind UI completion to the exact original Feature operation, instance, Capture Arc and selected
  final texture. Validate its actual original typed encode report before consuming output admission.
  Successfully drawing an unrelated UI branch cannot authorize that final image.
- Expose atomic selected-policy UI capture through `can_capture_with_ui` and `capture_with_ui`;
  refusal returns the original sidecar. Replayable paint data contains no one-shot permission.
- Complete the trusted backend handoff through `WgpuUiSubmission::into_prepared_submissions` and
  `nara_ui_render::advanced`. Prepared transfer moves original attempts; bound transfer refuses
  and returns the same sidecar. Batch binding checks all retry generations before binding any
  member. Public naming does not expose constructors for permits or unchecked binding.
- Preserve recoverable policy-content rejection and contain public validation/build panics as
  structured errors. Topology/source ownership violations retain Runtime fault behavior.
- Account for fixed policy metadata, exact original-submission wrapper/counter increments and
  known native preparation before allocation. The private CPU policy table has 64 fixed slots and
  reclaims actual retired leases rather than retaining growing Vec capacity.
- Permit physical storage with a superset of declared native usages while retaining exact logical
  access, owner, shape and interpretation checks. Valid final readback no longer rejects merely
  because the realization includes attachment/copy capabilities.
- Preserve `DeviceLost` before healthy-device requirement reconstruction refusal. `prepare_policy`
  and Feature creation share the same checked requirement admission helper.
