# Result

The language fixture no longer imports `behavior_trial.rs` or any `__private` API. Definition
admission uses `ComponentSchemaOwnerSnapshot` and one real frozen native provider snapshot.
Compilation, complete native/data preparation, guarded enumeration/read, live export and exact
Scene retirement all use public `SceneComponentBindings` operations. Targets retain the exact
World, instance receipt and generational entity; resolution uses the current Scene owner rather
than a cached initial entity roster. A separately admitted equivalent definition cannot authorize
language capture. No post-native-commit carrier installation or test-owned export remap remains.

The same external three-Schema catalog drives actual C#/.NET and Lua callbacks without a native
field or Schema-ID extraction branch. Source edits use a real window-free `EditorProjectSession`,
with complete Label Attach templates, stable property IDs, prepared edits/construction, one
history operation each, Undo/Redo, actual Save, physical close and new-Host Reopen. JSON and RON
use separate temporary projects, real image bytes and canonical metadata. Reopened history is
empty; Name, Sensor assets and references survive editing and persistence unchanged.

Two repeated Prefab occurrences execute only against their own references. A real Sensor output
followed by another occurrence's live friend is rejected as one batch, leaving both Names
unchanged. Foreign Worlds and retired instances also reject. Complete export assertions compare
Mover, Sensor and Label records, including nested asset values and independently remapped friend
identity; exported scenes are materialized anew and Sensor/Label callbacks execute against them.

Language execution remains a separate experimental owner. Complete callback IDs/versions reject
missing, duplicate or wrong-version registrations without replacing the active predecessor.
The runner now builds a real C# candidate that omits Sensor, separately from the existing candidate
whose final Sensor version is wrong. Both are rejected, physically retired and observed collected
while the predecessor continues in the same World. Existing old-result fencing, same-path body
rebuild and actual held callback leases remain. Retirement refuses ordinary invocation while a
held lease can still call the old body; weak context death after lease release proves the tested
collectible context completed. Neither Drop, Unload request nor a polling limit substitutes for
that observation. Lua retains the corresponding actual VM-lease and bare-Function counterexample.

Deleted `behavior_representation.rs`, `support/behavior_trial.rs` and its storage module: these
contained a second preview/compiler/publication/handwritten-export Runtime. Their production
correctness guarantees map to existing Scene/Reflect and public consumer tests. The additional
setter regression starts with a valid self-link, retires another entity, rejects a new dead-target
link, then compares original Link, sibling Score, native Name and the complete successful export.
This avoids mistaking a rejection caused by an already-invalid existing record for success.

Two raw storage probes retain only selective logical inspection counts and direct-despawn orphan
retention/cleanup for the losing Rows alternative. They have no Scene materialization, Schema
admission, export, language or cleanup-hook adapter. Their counts exclude archetype metadata and
map lookup work and do not measure throughput, allocation, RSS or the production carrier.
